# 📁 Data Analytics Portfolio


This repository contains a collection of data analytics projects demonstrating skills in SQL, Python, Power BI, and Excel. These projects focus on solving real-world business problems using data analysis, visualization, and dashboarding.

Projects
1. E-Commerce Business Analysis (SQL Project)

Tools: SQL, Python (Faker), Excel, GitHub

Overview:
Designed a relational database, generated realistic business data, and analyzed sales, customers, and product performance using SQL queries ranging from basic to advanced levels.

Key Highlights:

Analyzed revenue trends and customer purchasing behavior

Identified high-value customers and top-performing products

Performed retention and pricing analysis

Created visual summaries in Excel


2. HR Analytics Dashboard

Tools: Power BI, DAX, Python

Overview:
Developed an interactive HR dashboard to analyze workforce performance, attrition, recruitment, and diversity metrics.

Key Highlights:

Built dashboards analyzing employee performance and attrition trends

Created DAX measures to track key HR metrics

Analyzed recruitment funnel and retention patterns

Provided insights for workforce planning and decision-making



3. Enterprise Data Analytics & Reporting Framework

Tools: Python, SQL, Power BI

Overview:
Analyzed transactional customer data to uncover spending patterns, customer trends, and key business insights.

Key Highlights:

Performed data cleaning and analysis using Python

Analyzed transactional records and customer segments

Built dashboards to visualize trends and insights

Delivered actionable recommendations based on data


4. Students Social Media Addiction Analysis

Tools: Python, Pandas, NumPy, Matplotlib, Seaborn

Overview:
Analyzed student social media usage data to identify patterns related to addiction levels and behavioral trends.

Key Highlights:

Performed data cleaning, preprocessing, and EDA

Conducted group-based behavioral analysis

Visualized patterns in usage and addiction severity

Identified relationships between usage time and addiction indicators
